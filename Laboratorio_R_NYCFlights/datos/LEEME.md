# Datos
Los datos originales de vuelos **no** se incluyen como CSV: se cargan desde el paquete oficial `nycflights13` al ejecutar los scripts.

`datos_alterados_didacticos.csv` es una **tabla sintética de demostración**, elaborada para ilustrar limpieza de cadenas, ausencias, errores de tipo y duplicados. **No representa observaciones verificadas de vuelos reales**; no se debe utilizar para inferencias sobre NYC 2013.
